# D12 — SSH 私钥导入方式

> 日期：2026-09-09  索引：[decisions.md](../decisions.md)
> 状态：现行（若与代码冲突，以代码与索引中标注的取代关系为准）。


- **日期**：2026-09-09
- **决策**：
  1. 导入方式：**文件选择器 + 粘贴文本**。
  2. 支持格式：**OpenSSH 私钥格式与 PEM**；**不支持 PPK**。
  3. **支持 passphrase**，加密存储，连接时用于解锁私钥。
  4. 界面**只显示指纹**与格式，不回显私钥正文。
- **背景**：私钥导入直接影响 UI 表单与凭据存储设计；客户明确排除 PPK（Windows 用户若需转换，需自行用 PuTTYgen 转成 OpenSSH/PEM）。
- **影响**：导入时需做格式探测与友好报错；指纹计算使用 SHA256（与 OpenSSH 一致）。
