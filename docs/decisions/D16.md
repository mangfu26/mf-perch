# D16 — 应用形态：托盘常驻

> 日期：2026-09-09  索引：[decisions.md](../decisions.md)
> 状态：现行（若与代码冲突，以代码与索引中标注的取代关系为准）。


- **日期**：2026-09-09
- **决策**：
  1. 关闭窗口 → **最小化到系统托盘**，应用与 MCP Server 持续运行。
  2. **托盘图标常驻**，菜单含"打开主界面"与"退出"。
  3. 真正退出前若有活跃终端，给出确认提示。
  4. 开机自启二期再做，设置页预留位置。
- **背景**：MCP Server 运行于应用进程内（D2），关窗即退出会导致 Agent 断连、长命令中断。客户认同"本应用实质是 Agent 的终端访问代理"。
- **影响**：需实现托盘图标与菜单；退出流程需检查活跃终端并二次确认。
