# D7 — 工程原则 P1 / P2

> 日期：2026-09-09  索引：[decisions.md](../decisions.md)
> 状态：现行（若与代码冲突，以代码与索引中标注的取代关系为准）。


- **日期**：2026-09-09
- **决策**：确立两条工程原则，见 [`docs/design/principles.md`](../design/principles.md)。
  - **P1 不假设运行环境存在外部依赖**：探测优先、优雅降级、明确报错、禁止静默降级、优先内建能力。
  - **P2 安全降级必须显式告知**：安全强度下降时必须在界面明确告知并由用户确认。
- **背景**：项目中两次出现"假设环境存在某组件"的问题（目标主机 base64、Linux 系统钥匙串），均由客户指出。
- **影响**：后续所有设计评审须检查这两条原则；涉及外部依赖或安全降级的功能需在设计中说明探测与降级路径。
- **后续增补（本条只记 P1/P2，原则清单本身在增长）**：权威清单始终是
  [`docs/design/principles.md`](../design/principles.md)——
  **P3**（安全属性必须有能区分对错的测试）源于 2026-09-10 的全量安全审计，
  当时以审计结论形式确立、**未单独立 ADR**；
  **P4**（遇到障碍求助、不得用绕过手段维持推进）见 **D51**。
  新增原则时以 principles.md 为准，不必回来改本条标题。
