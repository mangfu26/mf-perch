# D9 — SSH 协议库：russh

> 日期：2026-09-09  索引：[decisions.md](../decisions.md)
> 状态：现行（若与代码冲突，以代码与索引中标注的取代关系为准）。


- **日期**：2026-09-09
- **决策**：SSH 客户端实现采用 [`russh`](https://github.com/Eugeny/russh)（纯 Rust、Tokio 异步、无 C 依赖）。
- **背景**：候选还有 `ssh2`（libssh2 绑定，成熟但依赖 native 库）。因客户要求跨平台架构，`ssh2` 的 native 依赖会在 Windows 及未来 macOS/Linux 打包时反复带来麻烦；`russh` 与 Tokio 异步运行时契合。
- **影响**：
  - 无 native 依赖，Tauri 跨平台打包更干净。
  - 编码前需核实当前版本对 ProxyJump、keepalive 等特性的支持（Q9 范围内）。
  - 认证实现基于 russh 的 client handler 接口。
