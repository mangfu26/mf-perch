# D8 — 首发平台与跨平台架构

> 日期：2026-09-09  索引：[decisions.md](../decisions.md)
> 状态：现行（若与代码冲突，以代码与索引中标注的取代关系为准）。


- **日期**：2026-09-09
- **决策**：**首发仅 Windows**；架构必须遵循跨平台设计，为 macOS / Linux 桌面版预留支持。
- **背景**：客户开发环境为 Windows，首发聚焦 Windows 可加快联调；但客户明确要求架构不阻断未来跨平台。
- **影响**：
  - 平台相关能力抽象为接口：密钥存储（Q5）、应用数据目录、托盘与窗口行为、系统通知、开机自启。
  - 禁止硬编码 Windows 路径或直接调用平台 API，须经抽象层。
  - CI 首发仅 Windows；跨平台构建配置预留但暂不启用。
