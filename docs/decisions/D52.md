# D52 — ADR 由单文件拆为「索引 + 分片」，整条失效的决策移入 archive

> 日期：2026-09-18  索引：[decisions.md](../decisions.md)
> 状态：现行

- **日期**：2026-09-18
- **状态**：**已实施**（本条即按新流程落地：新建分片 + 索引加行，未往索引塞正文）。
- **决策**：`docs/decisions.md` 从"全部正文单文件"改为 **索引 + 一条一个分片文件**
  （`docs/decisions/D<编号>.md`），并把**整条已被后续决策移除**的原文移入
  `docs/decisions/archive/` 标为快照。索引只保留：按域分组的一行式条目、
  **取代关系表**、以及使用规则。
- **背景（实测数据，不靠"感觉太长"下判断）**：
  - 拆分前：1262 行 / **92 KB** / 51 条；最长 8 条合计 472 行 ≈ 全文 37%（D47 一条 112 行）；
  - 接手的 Agent 为查一条决策要把全量吞进上下文，而**实际需要的往往只有一条**；
  - 更危险的是**已移除机制的原文与现行结论混排**：D37（按索要配对 FIFO）与 D44
    （拒绝记忆）描述的机制都已被 **D49 整体移除**，但仍躺在"现行"文件中间，
    容易被当成现行设计去实现——这正是 §4.1 要防的"失忆后推翻已确认结论"的反面情形；
  - 拆分方案的硬约束来自引用统计：`D<编号>` 形式在 `src-tauri/src` 出现 **225 处 / 33 个文件**
    （另有 tests 与前端），而写文件路径 `decisions.md` 的只有 **21 处 / 10 个文件**——
    **编号是跨语言外键，路径是软引用**。
- **决策要点（为什么是这套形态）**：
  1. **文件名保留 `docs/decisions.md`**：21 处软引用（含 AGENTS.md 8 处）**零改动**继续有效，
     因为它们写作"`docs/decisions.md` + 编号"，索引正好能满足；实测全仓库**没有任何**
     `decisions.md#锚点` 形式的引用，所以锚点不会失效；
  2. **分片文件名就是 `D47.md`**，不加英文 slug：编号即锚点，避免为 51 条发明英文名，
     也避开中文文件名的 URL 转义问题；
  3. **归档判据从严**：只有条目内**明确写有"已被 Dxx 整体移除"**的才进 `archive/`
     （经全量审计确认只有 D37、D44 两条）；**部分失效（10 条）一律不搬**——
     整条搬走会连带丢掉其中仍现行的结论（如 D11 的 sudo 三模式、D27 的测试环境、
     D33 的 `command_id` 配对），只改为在索引的取代关系表标注；
  4. **新增第三种时效性"部分失效"**（见 AGENTS.md §4.1）：ADR 条目特有，
     文档级仍只有现行 / 快照两种。
- **无损保证（P3 式思路：不能只看"跑通了"，要能区分对错）**：
  正文由脚本逐字搬运而非手写，并做**双向校验**——
  ① 原文 994 行非空正文在对应分片中**逐行命中、0 行缺失**；
  ② 分片侧非空行数 **994 = 994**，排除"搬多了/搬漏了"；
  ③ 7 处相对链接因目录加深补了 `../` 前缀，逐一核对；
  ④ 索引覆盖度检查：51 个分片**全部被链接、无孤儿、无重复链接**。
  校验脚本为一次性工具，放在被忽略的 `.tmp-test/`，不入库。
- **顺手修正的 5 处状态失真**（§4.3.4「状态要真实」；逐条经代码/仓库核实）：
  | 条目 | 失真 | 依据 |

  | D2 | 把 Q30 写成"待决风险"，实际 D30 已拍板暂不做 TLS | D30 条目本身 |
