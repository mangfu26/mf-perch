# D28 — 开源许可证：Apache-2.0

> 日期：2026-09-10  索引：[decisions.md](../decisions.md)
> 状态：现行（若与代码冲突，以代码与索引中标注的取代关系为准）。


- **日期**：2026-09-10
- **决策**：项目采用 **Apache License 2.0**。
- **背景**：客户计划后续开源；团队建议 Apache-2.0（宽松许可 + 明确专利授权，对企业采用友好），客户确认。
- **影响**：
  - 仓库根目录已放置完整 `LICENSE`。
  - 附录版权行**保留占位符**，不写入个人身份信息。
  - 后续需在 `package.json`、`Cargo.toml`、`tauri.conf.json` 中声明 `license = "Apache-2.0"`。
  - 若将来包含第三方代码，需保留其许可与归属声明（NOTICE 机制）。
