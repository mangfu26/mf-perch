# D20 — 归档终端的恢复语义

> 日期：2026-09-10  索引：[decisions.md](../decisions.md)
> 状态：现行（若与代码冲突，以代码与索引中标注的取代关系为准）。


- **日期**：2026-09-10
- **决策**：人类**可以恢复**归档终端；恢复后**沿用原终端 ID 与命令历史**，底层 SSH 会话重建。
- **背景**：Agent 可能误归档仍有用的终端，需要人类补救途径。客户确认允许恢复且延续原 ID 与历史。
- **影响**：
  - 归档 ≠ 终结，终端实体可复活；仅"人类删除"才是终态。
  - 恢复需重建 SSH 会话与包装脚本，需做配额校验（Q11）。
  - 恢复行为记入审计日志。
