# D2 — MCP 端点暴露方式、鉴权与端口策略

> 日期：2026-09-09  索引：[decisions.md](../decisions.md)
> 状态：现行（若与代码冲突，以代码与索引中标注的取代关系为准）。


- **日期**：2026-09-09
- **决策**：
  1. **监听地址**：默认仅监听 `127.0.0.1`；提供"允许远程连接"开关，开启后监听 `0.0.0.0`。
  2. **鉴权**：应用自动生成随机 Bearer Token，设置页可查看、复制、重置；客户端手动配置该 Token。
  3. **端口策略**：首次安装启动从 `50001` 开始递增寻找可用端口，首个成功端口持久化；下次启动优先使用持久化端口，若被占用则重新从 `50001` 开始递增寻找并再次持久化。
- **背景**：客户不限定 MCP 客户端所在主机，Agent 可能与 GUI 应用不在同一台机器上，因此需要可选的远程访问能力。
- **影响**：
  - 默认监听回环地址，安全默认值；远程连接需用户显式开启。
  - 端口号持久化在本地配置中；端口选择逻辑需处理"持久化端口被占用"与"重新搜索"两种路径。
  - **已结案风险（Q30 → D30）**：远程模式下的传输安全。仅 Bearer Token 无加密——
    **已由 D30 拍板"暂不启用 TLS"**，客户在局域网场景接受该残余风险，
    并保留为未来工作。**不要再当作待决事项重新提问。**
