# D13 — 终端数量配额

> 日期：2026-09-09  索引：[decisions.md](../decisions.md)
> 状态：现行（若与代码冲突，以代码与索引中标注的取代关系为准）。


- **日期**：2026-09-09
- **决策**：
  1. 配额：**每主机 5 个**、**全局 20 个**，均可在设置中配置。
  2. 超限**拒绝创建**并返回明确错误；**不自动归档**，由 Agent 自行决定。
  3. **归档终端不占配额**（仅统计活跃终端）。
- **背景**：Q4 确定并行需多终端，需防止 Agent 无限创建拖垮应用或目标主机。
- **影响**：创建终端路径需做两级配额校验；错误信息需引导 Agent 归档不用的终端。
