# D19 — 命令历史审计能力范围

> 日期：2026-09-10  索引：[decisions.md](../decisions.md)
> 状态：现行（若与代码冲突，以代码与索引中标注的取代关系为准）。


- **日期**：2026-09-10
- **决策**：MVP 提供**时间线查看 + 全文搜索 + 按终端/主机筛选**；**导出功能放二期**。
- **背景**：人类是本产品的"日志审核者"，审计能力属核心功能。全文搜索用 SQLite FTS5 实现，成本可控；导出涉及格式设计与额外工作量，故延后。
- **影响**：
  - 数据模型需为命令与输出建立 FTS5 索引。
  - 历史详情页支持展开完整输出、标注截断。
  - 导出能力二期设计（CSV / JSON / 文本）。
