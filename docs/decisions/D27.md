# D27 — 测试环境：WSL Ubuntu

> 日期：2026-09-10  索引：[decisions.md](../decisions.md)
> 状态：现行（若与代码冲突，以代码与索引中标注的取代关系为准）。


- **日期**：2026-09-10
- **决策**：使用客户本机的 **WSL Ubuntu 26.04** 作为测试目标环境；在其内运行 openssh-server（`127.0.0.1:2222`），Windows 侧通过真实 SSH 协议连接。
- **背景**：客户本机为 Windows 10，建议使用 WSL；团队探测确认原本无 WSL 发行版，客户安装后完成搭建。
- **实测结论**：
  - 密钥认证、命令执行、`bash -l` 环境加载、NUL 分帧协议、sudo 免密探测、fail-closed、askpass + FIFO 投递均验证通过。
  - **`bash -l` 的必要性得到实测证实**（默认非登录 shell 下自定义 PATH 不生效）。
  - **发现并修复设计缺陷**：`sudo -A` 将 askpass 的 stdout 第一行视为密码，故"请求标记"必须写 **stderr**；`docs/design/sudo.md` 已修正。
- **影响**：
  - 该环境可直接用于编码阶段的集成测试与回归验证。
  - 测试凭据（本地测试口令）为本地假值，仅存在于 WSL，**不入仓库**。
  - 老 RHEL `Defaults requiretty` 等真机特例无法在 WSL 覆盖，上线前建议真机抽验。
