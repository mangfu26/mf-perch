# D41 — 不提供文档站点；关于页只保留源码仓库外链

> 日期：2026-09-12  索引：[decisions.md](../decisions.md)
> 状态：现行（若与代码冲突，以代码与索引中标注的取代关系为准）。


- **日期**：2026-09-12
- **决策**：**不建立文档站点**（现在没有、后续也不打算建）。
  设置 → 关于卡片移除"文档"入口，**只保留「源码仓库」外链**
  （`https://github.com/mangfu26/mf-perch`）。
- **背景**：客户在打磨关于页时明确：没有文档网站，也不计划建；
  原来那个"文档"按钮既无落地页、也没有点击行为（纯摆设）。
  同时发现"源码仓库"按钮**同样没有绑定点击事件**——点了没反应，本次一并接上 `openUrl`。
- **影响**：
  - `SettingsView.vue`：移除文档按钮；`REPO_URL` 常量 + `openUrl` 绑定
    （遵循 D23 精神：外链只由用户点击触发，不自动打开浏览器）；
  - `zh-CN.ts`：删除 `settings.docs` 文案键，并就地注明"刻意没有文档一项"。
- **为什么值得记一条**：仓库里有大量 Markdown 文档（`docs/`），后来者看到关于页
  没有文档入口，很可能"顺手补上"——这条决策正是防止这种回改。
  `docs/` 是**面向团队与维护者的记忆库**，不是对外发布的站点。
- **相关**：D23（更新检查与下载页外链）、D28（Apache-2.0 许可）。
