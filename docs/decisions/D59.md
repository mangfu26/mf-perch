# D59 — 入口索引只写定位，不写能从被索引对象自身导出的内容

> 日期：2026-09-22  索引：[decisions.md](../decisions.md)
> 状态：现行

- **决策**：把 **D57** 的判据从"统计数字"一般化为一条——**凡是能从被索引对象自身得到的内容，
  都不抄进现行文档的入口**，包括：
  - **编号区间**：`D1–D56`、`Q1–Q36` 一类"到几号为止"；
  - **成员清单**：某目录"现含 D37、D44"这类点名；
  - **指向别处清单的计数词**："前端共有三道门禁""配套四条纪律"。

  改写为**现取**（`ls docs/decisions/`、`git grep -c`、`cargo test -j 2`）或
  **指向权威落点**（"条目到几号以该文件为准"）。规则条文已落在
  [`AGENTS.md`](../../AGENTS.md) §4.3 规则 8。
- **判据（两问）**：
  1. 打开它所指的文件、或跑那条命令，能不能自己得到这个内容？能 → **不登记**；
  2. 若保留一个计数：它的枚举**是否在同一句里**？
     - 在（"查三处：定义 / 注册 / 调用"）→ 安全，改枚举必然改到这句话；
     - 不在，指向下方或别处的表 → 危险，**加一行表项不会提醒人回来改数**。
- **背景**：客户 2026-09-22 提出"入口要索引的是'这块是什么'，1、2、3 是什么 Agent 自己能找到"。
  直接证据是同一份索引里两处已经错了：`AGENTS.md` §4.2 写"按域索引全部 **D1–D56**"，
  而当时编号已到 **D58**、分片文件数是 **56** 个——**同一个字符串既不是编号区间也不是文件数**；
  "需求澄清清单（**Q1–Q36**）"在三天内被 Q37–Q40 越过。这类数字的维护成本没人付，
  留下的却是"看着权威、其实是错的"读数，比不写更容易误导接手的 Agent。
- **与 D57 的关系**：**扩展，不是推翻**。D57 只覆盖"可由代码或测试自身导出的数量"，
  本条把同一条判据推广到区间、成员清单与计数词；D57 的两类豁免继续有效。
- **不受本条约束（不要顺手删）**：
  1. **快照文档与 ADR 里带日期的实测读数**（D57 边界 1）——记的是"当时测到什么"，删了等于销毁证据；
  2. **本身就是权威**的清单：`AGENTS.md` §4.4 已知缺口表、§4.6 债务表、
     本索引 §3 取代关系表、§4.2 文档清单本身——它们是原始记录，不是副本；
  3. **同一句内自带枚举**的计数（见上面判据第 2 问）。
- **影响**：`AGENTS.md` §4.2（decisions 行 / archive 行 / "外键"注里的引用量级）、
  §4.3 规则 8 改写、§5.9 与 §5.10 与 §5.11 去掉指向别处的计数词；
  `docs/decisions.md` §1 的引用量级改为指向 **D52** + 现取命令。
- **相关**：**D57**（本条一般化的对象）、**D53**（单一落点、只写现行事实）、
  **D52**（编号即外键、拆分当时的实测统计）。
