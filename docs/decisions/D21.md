# D21 — 删除终端：历史一并删除

> 日期：2026-09-10  索引：[decisions.md](../decisions.md)
> 状态：现行（若与代码冲突，以代码与索引中标注的取代关系为准）。


- **日期**：2026-09-10
- **决策**：人类删除终端时，**连同该终端的全部命令历史一并删除**，不可恢复；删除需二次确认。
- **背景**：Q12 已确定用户通过"手动删除归档终端"释放磁盘空间，若历史保留则空间无法释放；同时避免产生"无主历史"记录与数据模型复杂度。
- **影响**：
  - 删除是终端生命周期的终态，与"归档（可恢复）"区分明确。
  - 删除路径需二次确认并明确提示历史不可恢复。
