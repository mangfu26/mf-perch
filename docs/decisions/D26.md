# D26 — 页面清单

> 日期：2026-09-10  索引：[decisions.md](../decisions.md)
> 状态：现行（若与代码冲突，以代码与索引中标注的取代关系为准）。


- **日期**：2026-09-10
- **决策**：人类侧共 **5 个页面**：
  1. **SSH 主机**（主机管理）
  2. **认证信息**（凭据管理）
  3. **终端与审计**（终端列表 + 命令历史，**合并**）
  4. **设置**
  5. **关于**（版本、手动检查更新、文档、许可、MCP 配置示例）——**作为设置页内的子页/tab，不占一级导航**。
- 一级导航实际为 **4 项**：SSH 主机 / 认证信息 / 终端与审计 / 设置。
- **背景**：团队初版规划为"终端页 + 命令审计页"两个页面，客户决定先合并；客户指出缺少"关于"页（需承载手动检查更新）；首次引导页暂不做。
- **影响**：终端与审计合并后，页内以"分组浏览"与"全局搜索"两种入口组织。
