# D30 — 远程连接暂不启用 TLS（Q30）

> 日期：2026-09-10  索引：[decisions.md](../decisions.md)
> 状态：现行（若与代码冲突，以代码与索引中标注的取代关系为准）。


- **日期**：2026-09-10
- **决策**：**暂不支持 TLS**，允许在仅有 Bearer Token 认证的情况下开放远程连接。
- **背景**：客户评估后认为风险可控，理由：
  - 启用远程连接的典型场景是**局域网内主机互联**（公司内网或个人家庭局域网）；
  - 这类网络中中间人攻击与流量嗅探一般不会发生；
  - Bearer Token 已挡住未授权访问，只是传输未加密。
- **影响**：
  - 现有安全措施：Token 鉴权（常量时间比较）+ 默认仅监听回环 + 开启远程时的界面风险告警。
  - **已知残余风险**：开放远程连接后，Token 与命令内容在网络上以明文传输。若在公共网络或不可信局域网中使用，存在被嗅探的可能。
  - 保留为**未来工作**；届时可考虑 TLS、或改为仅监听回环 + SSH 隧道接入。
