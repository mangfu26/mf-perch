# D17 — 使用模型：单机单用户

> 日期：2026-09-09  索引：[decisions.md](../decisions.md)
> 状态：现行（若与代码冲突，以代码与索引中标注的取代关系为准）。


- **日期**：2026-09-09
- **决策**：**单机单用户**，不做账户体系、登录、权限分级与多租户隔离。
- **背景**：产品定位为个人使用 AI Agent 管理自有服务器；账户体系与核心价值无关。团队建议单机单用户，客户确认。
- **影响**：
  - 无需认证/授权模块，架构简化。
  - 数据按操作系统用户隔离。
  - 未来团队协作走"各自部署 + 数据同步"路线（Q32）。
