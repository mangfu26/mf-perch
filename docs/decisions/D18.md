# D18 — 界面语言：i18n 结构 + 首发简体中文

> 日期：2026-09-09  索引：[decisions.md](../decisions.md)
> 状态：现行（若与代码冲突，以代码与索引中标注的取代关系为准）。


- **日期**：2026-09-09
- **决策**：
  1. 前端引入 **vue-i18n**，所有界面文案走 key，**禁止硬编码**。
  2. 首发仅提供 **zh-CN** 语言包；语言切换入口在设置页预留。
  3. **MCP 工具描述与返回内容固定英文**，不随界面语言变化。
- **背景**：客户考虑后续开源，i18n 结构成本低但事后改造代价大，故预留结构、首发不增加翻译负担。
- **影响**：编码规范要求文案不硬编码；代码评审需检查。
