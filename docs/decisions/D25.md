# D25 — 终端审计页形态：时间线卡片

> 日期：2026-09-10  索引：[decisions.md](../decisions.md)
> 状态：现行（若与代码冲突，以代码与索引中标注的取代关系为准）。


- **日期**：2026-09-10
- **决策**：人类侧的终端审计页采用**时间线卡片**形态，每条命令一张卡片（命令、输出可展开、退出码、耗时、状态标签）；**不做终端回放视图**。
- **背景**：人类在本产品中的定位是"日志审核者"，审计场景下每条命令的边界与结果比终端观感更重要；备选的终端回放难以标注单条命令的状态与耗时。
- **影响**：命令历史数据结构需支持按条组织；UI 需提供卡片展开/折叠与状态标签。
